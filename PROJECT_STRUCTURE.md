## 🎯 Folder Purposes

### `unprocessed/`
**Purpose:** Input queue  
**Your action:** Drop floor plan PDFs here  
**Script action:** Reads and processes files from here  
**After processing:** Files moved to archived/

### `cleaned/`
**Purpose:** Output directory  
**Your action:** Retrieve cleaned PDFs from here  
**Script action:** Saves all outputs here  
**Contents per PDF:**
- `filename_cleaned.pdf` - Cleaned floor plan
- `filename_preview_original.png` - Before image
- `filename_preview_cleaned.png` - After image

### `archived/`
**Purpose:** Backup storage  
**Your action:** Restore if needed  
**Script action:** Moves original PDFs here  
**Safety:** Originals never deleted

---

## 🔄 File Lifecycle

```
Stage 1: Input
──────────────
floor_plan.pdf → unprocessed/floor_plan.pdf
(You place it here)

Stage 2: Processing
───────────────────
Script reads: unprocessed/floor_plan.pdf
Script cleans, optimizes, generates previews

Stage 3: Output
───────────────
Script creates:
  • cleaned/floor_plan_cleaned.pdf
  • cleaned/floor_plan_preview_original.png
  • cleaned/floor_plan_preview_cleaned.png

Stage 4: Archiving
──────────────────
Script moves:
  unprocessed/floor_plan.pdf → archived/floor_plan.pdf

Final State
───────────
✓ Cleaned version in cleaned/
✓ Original backed up in archived/
✓ unprocessed/ empty (ready for next batch)
```

## 🎓 Usage Patterns

### Pattern 1: Single PDF

```bash
cp single_plan.pdf unprocessed/
python3 process_floor_plans.py
# Result: 3 files in cleaned/, original in archived/
```

### Pattern 2: Batch Processing

```bash
cp batch_of_plans/*.pdf unprocessed/
python3 process_floor_plans.py
# Result: 3 files per PDF in cleaned/, all originals in archived/
```

### Pattern 3: Continuous Workflow

```bash
# Day 1
cp day1_plans/*.pdf unprocessed/
python3 process_floor_plans.py

# Day 2
cp day2_plans/*.pdf unprocessed/
python3 process_floor_plans.py

# Cleaned/ accumulates all outputs
# Archived/ accumulates all originals
```

## 🔧 Maintenance

### Periodic Cleanup

```bash
# After validating cleaned PDFs work correctly:

# Option 1: Compress old archives
cd archived/
tar -czf archive_backup_$(date +%Y%m%d).tar.gz *.pdf
mv archive_backup_*.tar.gz ~/Backups/
rm *.pdf

# Option 2: Clean old preview images
cd cleaned/
find . -name "*_preview_*.png" -mtime +30 -delete
```

### Archive Management

**Keep archived/ contents for:**
- At least 30 days
- Until cleaned versions validated
- As long as storage permits
